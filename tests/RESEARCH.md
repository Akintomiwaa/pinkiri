# Research verification

Run `node --experimental-strip-types --test tests/*.test.mjs`, `npx tsc --noEmit`, and `npm run build` with Node 22.13+.

Local research uses server-only GEMINI_API_KEY and FIRECRAWL_API_KEY. The endpoint requires a localhost host and matching Origin. Do not publish this endpoint without authentication and per-user budgets.

Flow: homepage context → structured brand/category search plan → five past-month public-index searches → up to six individual social page reads → cited findings and strategy. Homepage and successful social collection caches expire after one hour in the running process. Search failures and quotas are visible; no paid fallback or fabricated social data is used. Gemini generation uses a primary and backup model with bounded outage handling.

Search results do not guarantee accessible comments, publication recency, correct product identity or representative demand. Only scraped text enters the report, not search snippets. Unrelated/uncertain findings are excluded; invalid citations are rejected and unsupported quotations removed. Product/category relevance is an AI interpretation and should be reviewed against sources.

Manual checks: submit a real website from the existing landing input; inspect platform coverage and findings, follow citations, check all four strategy areas, edit/copy drafts, and download JSON. Empty social evidence must produce explicitly provisional homepage hypotheses. Export is report data (JSON), not a PDF; publishing and the specialist-agent cards remain previews.
